# 日报质量问题汇总（2026-09-17 / 09-18 两期 review）

## P0：AI 海报 8 条摘要全是占位文本

**现象**：09-18 `AI.png` 每条新闻下方都是同一句"这是一条新闻的简短摘要，展示核心内容要点，帮助快速了解……"，海报除标题外零信息量。

**根因**：`buildAiContextualPrompt`（`src/image-gen.mjs`）只往生图 prompt 里注入了标题，没有注入摘要；vault 提示词模板里每条有"简短摘要"槽位，图像模型拿不到真实摘要就用占位文字填充了。

**修复**：`collectAiHeadlines` 同时收集清洗后的 snippet（1~2 句），prompt 里按"标题 + 真实摘要"注入，并加显式指令：缺摘要时只显示标题，绝不使用占位文字。

## P1：参考来源标题残留 markdown 碎片

**现象**：09-18 `AI.md` 参考来源如 `- [3 分钟用完 Codex 5 小时额度\]\(/t/1242585#reply21\) **\[CyanHaze\]\(/member/CyanHaze\)** • 34 mins ago • Lastly replied by ……](<https://www.v2ex.com/t/1242585>)`，转义符和回复元数据原样出现在链接文字里。

**根因**（两处）：
1. `parseV2exTopics`（`src/v2ex.mjs`）的标题正则 `\[([^\n]{2,300})\]` 是贪婪匹配，会跨过 `[...](...)` 边界一路吞到最后一个 `](/t/<id>`，把"标题](/t/xxx) **[用户](/member/xxx)** • 34 mins ago …"整串抓成标题。
2. `ai-news.mjs` 参考来源区只做字符转义，没有先剥离标题里内嵌的 markdown 语法。

**修复**：v2ex 正则标题部分排除 `[` `]`（`[^\n\[\]]{2,200}`）；新增 `stripMarkdown()`，参考来源与海报标题在转义前先转纯文本。

## P1：海报与正文素材口径不一致

**现象**：09-18 海报列的是论坛热帖（Union Alpha、Qwen 3.8 Omni Flash…），正文写的是官宣动态（Anthropic LSVP、GPT-6 Astra…），海报标题却叫"AI 资讯摘要"，读者对不上。

**修复**：`aiNewsSection` 返回正文实际引用的 `citedSources`，`run.mjs` 里海报改用它（无引用时回退全量来源），海报即正文要点的可视化。

## P2：GitHub 海报第 6~10 名排版重叠

**现象**：09-18 `GitHub.png` 前 5 名间距正常，后 5 名描述文字与右侧数据框重叠。

**修复**：`buildContextualPrompt` 追加排版硬性要求（统一行高、描述与数据框不重叠、空间不足时缩短描述而非压缩行距）。注：最终视觉由 vault 提示词模板控制，代码侧只能加约束。

## P2：GitHub 文字版表格缺"语言"列

**现象**：trending 表格只有排名/仓库/简介/新增/总 star，看不出技术栈。

**修复**：`parseTrending` 解析语言行（描述行之后、数字行之前的单 token 行），表格加"语言"列。

## P2：提问帖被当成资讯条目

**现象**：09-17 海报第 7 条是 v2ex 网友提问"用 codex 找特价机票靠谱吗"；09-18 正文也不得不加段声明"爆料、测试中或尚未官宣"。

**修复**：`SYSTEM_PROMPT` 加第 11 条策展规则——纯求助/提问帖（疑问句式、"靠谱吗""求推荐"类）不单独成条，除非其回复中出现了可核实的官方信息。

## P3：双通道正文互不可见

**现象**：`AI.md` 和 `AI-Gemini.md` 同一天讲的故事差异很大（一个讲官宣、一个讲安全事件+华为算力），只看一篇会有偏差。

**修复**：`run.mjs` 双通道都运行时，在各自 H1 下加一行 `> 🔀 另一模型视角：[[AI-Gemini]]` / `[[AI]]` 互链。
